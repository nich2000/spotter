# Проверка макета состояния — этап 2

Сохранены согласованные порядок, диаметры, толщина/зазоры колец и цветовые пороги. Исправлены:

- Подтверждение и демонстрационные счётчики сохраняются отдельно для выбранной даты; возвращение к дате восстанавливает их.
- Обычное сохранение не подтверждает автоматически значения 0/0 и самочувствие. Явный переключатель сохраняется вместе с записью.
- Невалидные сон/шаги исключены из расчёта кольца; скрытая ошибка раскрывает секцию.
- Нулевые дуги не рисуют круглую точку вместо отсутствующей активности.
- Пустая дата возвращает действующую дату, подпись глюкозы следует выбранной единице.
- Пустые счётчики в краткой сводке показываются как неуказанные; длинные значения не раздвигают мобильный экран.

Playwright/Chrome: пройдены пары привычек 0/0, 1/0, 0/1, 5/2, 6/2, 10/4, 11/0, 0/5; сохранение без подтверждения; подтверждение и возврат даты; отсутствие данных/нулевая дуга; половина сна при 3,5 часа, полная активность при 10000 шагов; высокий стресс меняет цвет; отрицательное значение раскрывает ошибку; единицы и сохранение измерений по датам; 320px без горизонтального overflow. Нет JS runtime ошибок. Тест tests/wellbeing-browser.cjs и screenshot рядом. Для действий после раскрытия секции тест ждёт стабилизации preview iframe.
