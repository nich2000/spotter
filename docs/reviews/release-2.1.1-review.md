## Оставшиеся ограничения

- Снимок более 256 KiB по-прежнему нельзя доставить текущим протоколом. Он требует отдельного решения для пакетирования/лимитов без частичного замещения календаря. Увеличение числа записей не снимает ограничение размера сообщения.
- Отозванное согласие на здоровье или отклоненный пакет сохраняют файл очереди для проверки; fail-fast Flush может задерживать последующие пакеты. Автоматическое удаление таких данных не добавлено.
- Старые клиенты без `sourceSnapshotId` используют существующую проверку candidateVersion; эта версия пока не повышается при каждом обновлении источника.
- Статическое ревью и unit/race-тесты не подтверждают Apple Automation permissions, чтение реальных приложений Mac или физическую доставку пользовательских данных.
