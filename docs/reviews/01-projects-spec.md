# Проверка ТЗ проектов — этап 1

Проверены пользовательские решения о группировке, выборе ветки, нижнем вводе, двойном клике и переносе, а также общие контракты карточки, рабочего дня и статистики.

## Исправлено

- Явно задан родитель нового проекта и назначение системной группы «Без проекта».
- Закрыта гонка быстрого ввода: выбранный проект фиксируется при отправке, ответ не стирает последующий ввод.
- Перенос не меняет назначение нижнего ввода и не переписывает исторические снимки/время; перенос в ту же ветку не даёт ложное событие.
- Для регулярного выполнения отделён перенос экземпляра от изменения будущего расписания; вариант оставлен предложением.
- Уточнены счётчики при скрытии завершённых и пересчёт при повторном открытии.
- Миграция не объединяет разные старые названия из-за скрытой нормализации.

## Открыто

Глубина сверх обязательных трёх уровней; одинаковые названия соседей; перенос проекта шаблона регулярной задачи; показ завершённых по умолчанию.

## Междокументно

Историческая атрибуция проекта должна совпадать с ТЗ статистики. Общая карточка должна согласовать область изменения проекта регулярной задачи. Создание/переименование папок остаётся структурной операцией без добавления проектного планирования.

Проверка: повторное чтение правок и `git diff --check`. Код и макеты не менялись, коммит не создавался.
