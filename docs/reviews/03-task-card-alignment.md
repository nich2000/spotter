# Соответствие ТЗ и макета карточки задачи

| Требование | Результат | Граница |
|---|---|---|
| Компактность, четыре свёрнутых раздела | Соответствует, проверено браузером | Реальная модальность при интеграции ещё нужна |
| Название, описание, проект и состояния | Соответствует демонстрации | Полный список проектов со стабильными ID/путями поступает из приложения |
| Сложность: простая/средняя/сложная, средняя по умолчанию | Исправлено: добавлено поле, сохранение и отмена | Историческое значение требует общего серверного контракта |
| Дедлайн с датой без обязательного часа | Исправлено: отдельные дата и необязательное время | Граница дня в образце локальная; production использует пояс пользователя |
| Трудоёмкость, остаток, дневной объём, назначенное выполнение | Соответствует базовая независимость | Серверная валидация и календарный бюджет не реализованы |
| Несохранённый черновик при обновлении host | Исправлено: не перезаписывается входящим состоянием | Полный UI разрешения HTTP 409 — разработать |
| Заметка продолжения и причины ожидания/фона | Соответствует после этапа 2 | Серверная история снятых проверок — разработать |
| Подпункты | Частично: добавление, удаление и чекбокс | Редактирование, порядок, стабильные ID — реализовать |
| Комментарии и история | Частично: черновик сохраняется/отменяется | Даты, события, исполнение другим человеком — реализовать |
| Повторения без дублей | Визуальные поля и подпись | Планировщик, отдельное правило/выполнение, опережение каждого периода — реализовать |
| Единая карточка из разделов | Требование сохранено в ТЗ | Standalone образец не доказывает общую интеграцию |

В ТЗ добавлен явный раздел границ демонстрации. Требования не ослаблены под образец. Блокирование интервала после дедлайна остаётся предложенным поведением, а не утверждённым решением пользователя.

Проверка: `node docs/reviews/tests/task-card-alignment.cjs` (реальный Chrome, direct fragment) — PASS: свёрнутость, значение сложности по умолчанию, сохранение/отмена сложности, дата без времени, проверка времени дедлайна, сохранение черновика при конфликте, 320 px без переполнения. Direct fragment не проверяет экспортный iframe/общий modal host. Export пересобран render.py --force. Код приложения не изменён.
