# Inbox: соответствие ТЗ и образца

| Область | Результат |
|---|---|
| Компактные строки, матрица, источник, оценка | Соответствует демонстрационному объёму; 320/1024 без overflow |
| Открытие по названию | Соответствует: настоящий modal основных полей, не нижняя панель |
| Отдельное меню ⋯ | Соответствует: классификация, план, завершение, пропуск |
| Повторный разбор с прежним приоритетом | Исправлено: открытие/сохранение редактора больше не снимает review без выбора квадранта |
| Прямое завершение | Соответствует; исправлена потеря связи с планом, добавлена явная отмена последнего завершения |
| Возврат фокуса после сохранения | Исправлено через общий closeDialog после перерисовки |
| Описание состояния образца в ТЗ | Исправлены устаревшие утверждения о нижней панели и отсутствии прямого завершения |
| Полная согласованная карточка | Требует реализации: образец использует честно подписанный сокращённый редактор; ТЗ не ослаблено |
| Подзадачи, повторение, текущий таймер | Требуют общей модели/команд, не имитируются локальными кнопками |
| Целевая дата и дневной объём | Требуют реализации; флаг «сегодня» макета не равен полноценному плану |
| Источники, дедупликация, миграция, история, конфликты | Требуют реализации и интеграционных доказательств |

## Проверка

`node docs/reviews/tests/inbox-alignment.cjs` — PASS в реальном Chrome на прямом DOM фрагмента: повторный разбор сохраняется после редактирования, завершение и отмена сохраняют текущий план, ширины 320/1024, отсутствие runtime ошибок. `git diff --check` — PASS. Standalone повторно экспортирован штатным render.py --force.

Проверка этого этапа не подтверждает pointer-координаты экспортной iframe-оболочки: ограничение предыдущего отчёта сохраняется. Не заявляется подключение приложений или синхронизация независимых макетов.
