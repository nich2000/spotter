# Проверка макета карточки — этап 2

Исправлены функциональные дефекты без изменения компактной компоновки:

- Черновые комментарии теперь входят в сохранение и отмену; сохранённые комментарии восстанавливаются вместе с полями.
- Заметка продолжения и причины ожидания/фона не перезаписывают друг друга при переключении состояний.
- Ошибка скрытого поля раскрывает секцию и переводит фокус; проверяется конец интервала относительно дедлайна.
- Отключённое расписание больше не показывается в сводке как повторяющееся.
- Длинные подпункты/комментарии переносятся; поля сетки не раздвигают мобильный экран.

Проверено Playwright в реальном Chrome: комментарии save/revert, сохранность resume, скрытые ошибки, конец за дедлайном, отключение повторения, отмена завершения с подпунктами, завершение и повторное открытие, отсутствие горизонтального overflow при 320px и отсутствие JS runtime ошибок. Скрипт: tests/task-card-browser.cjs. Снимки desktop/mobile сохранены рядом. node --check и git diff --check успешны.

Исходник отрендерен заново штатным render.py --force. Backend не добавлен. Полнота соответствия ТЗ (сложность, редактирование подпунктов, настоящая модальность и т.д.) проверяется отдельно этапом 3. Тестовый screenshot оболочки показывает прокручиваемую рамку iframe; проверена ширина самого содержимого, полной проверки всех экранных состояний скриншотом не заявляется.
