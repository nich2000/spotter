# Проверка ТЗ Моё состояние — этап 1

Проверены пожелания пользователя, ТЗ карточки/статистики, финальная геометрия сохранённого макета и описание моста сна в README. Изменён только wellbeing-spec.md.

## Подтверждено

- Последний порядок: вредные привычки снаружи, активность в середине, сон/самочувствие внутри.
- Полное внешнее кольцо с четырьмя цветами: 0/0 зелёный; до 5/2 жёлтый; до 10/4 оранжевый; выше красный. Это личные пороги, не нормы безопасности.
- Среднее кольцо всегда зелёное; внутреннее заполняется по сну и окрашивается по самочувствию.
- SVG 176px, радиусы 91/55/19 и толщина 18 дают равный толщине зазор. Текст в центре отсутствует.
- Подробные блоки свёрнуты; лишние блоки и связь заметки с задачей исключены.

## Исправлено

- Отличены размер SVG и видимый диаметр, приведены размеры толщины/зазора в CSS px.
- Уточнены неизвестные данные, нулевой сон/нулевые задачи, частичная доступность данных и уменьшение прогресса после исправления.
- Добавлено безопасное от ложных записей частичное подтверждение: сохранение измерения не подтверждает незаметно 0/0 и обычное самочувствие. Дефолты формы остаются как просил пользователь.
- Уточнены сохранённый часовой пояс, идемпотентность ручных измерений, происхождение конкретных полей.
- Выявлено и описано различие границы дня для исторического кольца и границы месяца для месячной статистики.
- Добавлены критерии приёмки.

## Решения, требующие согласования

1. Шкала эмоциональных категорий остаётся предложенной, не медицинской.
2. Смешанная сложность по текущему макету не суммируется, используется максимум; это предложение алгоритма.
3. Исторический дневник по состоянию на конец дня может отличаться от месячного отчёта при последующем повторном открытии. Нужна единая явная политика, нельзя обещать одинаковые числа без учёта границы.
4. Подтверждение групп отдельно — рекомендация для исключения фиктивных нулей при частичном вводе.
5. Связь ориентира 7 часов с существующей отдельной целью сна в настройках требует решения.

Приложение, формулы в макете и данные пользователя не изменялись.
