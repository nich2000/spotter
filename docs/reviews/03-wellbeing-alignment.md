# Соответствие ТЗ и макета «Моё состояние»

| Требование | Результат | Остаток |
|---|---|---|
| Компактный развёрнутый индикатор, остальные разделы свёрнуты | Соответствует | Проверено в Chrome |
| Порядок: вредные привычки → активность → сон | Соответствует | Радиусы 91/55/19, толщина 18; SVG 176 px |
| Зазор равен толщине, нет текста в центре | Соответствует | Общий внешний диаметр не менялся |
| Привычки: 0/0 зелёный, ≤5/2 жёлтый, ≤10/4 оранжевый, выше красный | Соответствует | Проверены граничные пары, полный круг во всех случаях |
| Активность зелёная, только заполнение, максимум альтернатив | Соответствует | Реальные задачи пока заменены demo регуляторами |
| Сон меняет заполнение, самочувствие — цвет | Соответствует | Точная эмоциональная шкала остаётся предложением |
| Подтверждение групп независимо | Исправлено | Два переключателя вместо объединённого |
| Не выдавать черновик за сохранённую запись | Исправлена видимая подпись расчёта | Долговечность/конфликты и timestamp подтверждений — разработать |
| Чтение показателей без различения цвета | Исправлено: проценты и названия категорий | Серый явно означает неподтверждённые данные |
| Дата не переносит default-подтверждение | Соответствует | Проверено сменой даты и сохранением |
| Сложность по умолчанию средняя | Текст и формула соответствуют | Общая карточка исправлена отдельным этапом; real completion stream ещё не интегрирован |
| Историческая граница wellbeing/statistics | Открытое решение | Не переписано под один экран |

В ТЗ добавлена явная граница между проверенным образцом и обязательной реализацией. Измерения в примере остаются текстовыми записями: ID, единицы/источник как структурированные поля, период среднего и UTC-время требуют production-модели. Реальный HealthKit не изображается подключённым. Дневник не отправляется в modelContent.

Проверка: `node docs/reviews/tests/wellbeing-alignment.cjs` — PASS (реальный Chrome, direct fragment). Проверены геометрия, независимые подтверждения, 8 пар порогов, независимость цвета и заполнения сна, шаги и альтернативная цель задач, новая дата и отсутствие неявного подтверждения при сохранении, отсутствие переполнения на 320 px. Direct fragment не доказывает поведение экспортной оболочки. Export пересобран render.py --force.
