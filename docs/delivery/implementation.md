## Что реализовано и что ещё не принято

Реализованы локальный вход, основные экраны React, общая карточка задачи, подзадачи/комментарии, квадранты входящих, проекты, текущий план дня, ручные записи самочувствия с согласием, настройки, регистрация/отзыв MacBook, зашифрованная очередь helper и подтверждаемый серверный импорт. Старые файлы не удалены; автоматическая миграция пользовательского workspace не выполнялась.

Полная приёмка исходного ТЗ пока не достигнута. Помимо согласованных ограничений R-политик, остаются: нормализованная предметная SQL-схема вместо JSONB workspace; публикация outbox и очистка retention; ротация device token; полные контракты пагинации/фильтрации; сохранение last-success при ошибке источника и полная сверка изменённых исходных объектов; UI управления файлами и всеми операциями проектов; безопасный повтор неизвестного результата команды в клиенте; проверенный backup/restore и миграция исторических данных. Историческая аналитика, таймер, recurrence, закрытие дня и расчётные показатели не выдаются за реализованные. Стенд предназначен для локальной проверки доступного объёма, не для публичного выпуска.

- Все строки со сроками остаются в списке вне видимого интервала; обрезается только изображение. Перенос обрезанной полосы сохраняет исходные полные границы.
- Перенос тела и правого края, превью дат, Escape/pointercancel, клавиатурная альтернатива, неизвестная трудоёмкость.
- Одна команда на завершённый перенос. Сетевой повтор сохраняет envelope, конфликт требует явного сравнения и открытия черновика. В общей карточке неизвестный исход запроса блокирует поля до повторного сохранения.

- API принимает прежний Scheduled без kind. PostgreSQL хранит интервалы и связи в общей задаче; обе стороны связи и событие меняются атомарно. Ручное планирование не меняет план дня/приоритет/фокус/учёт времени.
- Профиль capabilities публикует предупреждение при выходе за дедлайн; общие R5/R11/R12 этим не закрыты.
